🚀 Chapitre 1

Logique entrepreneuriale et managériale

🎯 Définition de l'entrepreneur

L'entrepreneur est une personne qui détecte une opportunité, prend des risques et mobilise des ressources afin de créer ou développer une activité économique.

Les qualités de l'entrepreneur

  • Créativité
  • Innovation
  • Prise de risque
  • Esprit d'initiative
  • Persévérance
  • Leadership
  • Capacité d'adaptation

Les formes de création d'entreprise

Création pure

Création d'une nouvelle activité qui n'existait pas auparavant.

Reprise d'entreprise

Rachat d'une entreprise déjà existante afin de poursuivre son activité.

🧠 Auteur à retenir : Joseph Schumpeter

Schumpeter considère que l'entrepreneur est le moteur de l'économie grâce à l'innovation.

Innovation ➜ Nouveaux produits ➜ Croissance économique

La destruction créatrice

Les innovations remplacent progressivement les activités devenues obsolètes.

Exemples :
  • Netflix ➜ Vidéoclubs
  • Spotify ➜ Disquaires
  • Uber ➜ Transport traditionnel

📋 Le projet entrepreneurial

La création d'entreprise suit plusieurs étapes.

  1. Trouver une idée
  2. Réaliser une étude de marché
  3. Élaborer un business plan
  4. Rechercher des financements
  5. Choisir un statut juridique

Étude de marché

Permet d'analyser :

  • les clients potentiels ;
  • les besoins ;
  • la concurrence ;
  • les opportunités.

Business Plan

Document présentant le projet, les objectifs, la stratégie et les besoins financiers.

Plan de financement

Permet de vérifier la faisabilité financière du projet.

👔 Définition du manager

Le manager coordonne les ressources de l'organisation afin d'atteindre les objectifs fixés.

Les missions du manager

  • Fixer les objectifs
  • Organiser les activités
  • Coordonner les équipes
  • Contrôler les résultats
  • Motiver les collaborateurs

Compétences du manager

  • Leadership
  • Communication
  • Organisation
  • Prise de décision
  • Gestion des équipes

🧠 Auteur à retenir : Peter Drucker

Pour Drucker, la mission essentielle du management est de créer et conserver un client.

📊 Comparaison Entrepreneur / Manager

Entrepreneur Manager
Crée l'activité Gère l'activité
Prend des risques Cherche à les limiter
Innove Optimise
Vision long terme Organisation quotidienne
Détecte les opportunités Assure la performance
