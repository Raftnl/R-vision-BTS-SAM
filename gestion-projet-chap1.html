💰 Chapitre 1 : Définir le projet et les modalités de son pilotage

🎯 Objectif du chapitre : Comprendre ce qu'est un projet, ses caractéristiques, son pilotage, ses indicateurs de suivi et les outils de communication associés.

📖 1. Définition d'un projet

Selon l'ISO 10006, un projet est un ensemble d'activités coordonnées et maîtrisées permettant d'atteindre un objectif précis dans le respect de contraintes de délai, de coût et de ressources.

Projet = Objectif + Ressources + Délais + Budget

⭐ Caractéristiques d'un projet

  • Temporaire (date de début et de fin)
  • Unique
  • Organisé autour d'un objectif
  • Mobilise des ressources
  • Présente des contraintes
  • Comporte des risques

📊 2. Les différents types de projets

Type Exemples
Projet Ouvrage Construction d'un pont, création d'une entreprise
Projet Produit / Service Lancement d'un produit ou d'un service
Projet Organisationnel / Événementiel Salon, séminaire, réorganisation d'un service

🧩 3. Les éléments constitutifs d'un projet

Élément Définition
Périmètre Ce qui entre ou non dans le projet
Contraintes Budget, délais, ressources, communication
Enjeux Ce que l'organisation peut gagner ou perdre
Risques Événements futurs pouvant nuire au projet
Jalons Dates importantes du projet
Livrables Productions attendues
Coûts Dépenses liées au projet
Date cible Date finale prévue
💡 BTS : Un risque est un événement futur et incertain. S'il se réalise, il devient un problème.

🚀 4. Les 5 étapes du projet

Étape Objectif
1. Initialisation Définir les besoins et les objectifs
2. Lancement Étudier la faisabilité du projet
3. Organisation Constituer l'équipe et planifier
4. Exécution & Suivi Réaliser le projet et mesurer les résultats
5. Clôture Évaluer les résultats et réaliser le bilan

👥 5. Les acteurs du pilotage

Le chef de projet

  • Coordonne le projet
  • Prend les décisions
  • Contrôle l'avancement
  • Gère les risques
  • Informe la hiérarchie

Le comité de pilotage

  • Valide les grandes orientations
  • Contrôle le respect des délais
  • Contrôle le budget
  • Suit les indicateurs

📈 6. Les indicateurs de suivi

Les indicateurs permettent de comparer les prévisions aux réalisations.

Objectif ≠ Indicateur

Objectif : Contacter 1200 clients

Indicateur : Nombre de clients contactés

Caractéristiques d'un bon indicateur

  • ✅ Indépendant
  • ✅ Réel
  • ✅ Orienté vers l'objectif
  • ✅ Vérifiable
  • ✅ Mesurable

Exemples d'indicateurs

  • Respect du budget
  • Respect des délais
  • Nombre de livrables réalisés
  • Taux d'avancement
  • Nombre d'accidents
  • Satisfaction des parties prenantes

📊 7. Les outils de pilotage

Outil Utilité
Tableau de bord Suivre les indicateurs
Diagramme de Gantt Planifier les tâches
Planning Organiser le projet
Budget Suivre les dépenses
Comptes rendus Suivre les réunions

📢 8. La communication de projet

Objectifs

  • Informer
  • Faire comprendre
  • Faire collaborer
  • Convaincre de l'utilité du projet

Cibles internes

  • Salariés
  • Managers
  • Direction

Cibles externes

  • Clients
  • Fournisseurs
  • Partenaires
  • Institutions

Supports de communication

  • Réunions
  • Newsletter
  • Courriels
  • Site internet
  • Réseaux sociaux
  • Affichage

📝 9. La note de cadrage

La note de cadrage est le document qui structure le projet. Elle est réalisée lors de la phase d'initialisation.

📌 Sans note de cadrage, le projet ne peut pas être correctement lancé.

Contenu de la note de cadrage

  • Nature du projet
  • Objectifs
  • Organisation du projet
  • Délais
  • Budget
  • Risques
  • Communication
  • Indicateurs de suivi

🎯 À retenir pour l'examen

  • Projet = objectif + ressources + délai + budget.
  • 5 étapes : Initialisation → Lancement → Organisation → Exécution → Clôture.
  • Le pilotage repose sur des indicateurs de performance.
  • Le diagramme de Gantt sert à planifier les tâches.
  • La communication facilite l'adhésion des acteurs.
  • La note de cadrage est indispensable au lancement du projet.
  • Les risques peuvent être organisationnels, humains, financiers, techniques ou juridiques.
